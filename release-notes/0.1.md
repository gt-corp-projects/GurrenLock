## Features

- Hero-specific animated loading screens for 22 supported heroes.
- Each video plays once, then its final frame remains visible until the loading screen closes.
- Heroes without a matching animation retain the standard loading screen.

## Installation

Install `GurrenLock_dir.vpk` using your Deadlock mod manager. Videos and final-frame images are installed separately in `game/citadel/panorama/videos/GurrenLock/`; see the [README](https://github.com/gt-corp-projects/GurrenLock#downloads-and-media) for file names and details.

The optional preview VPK is intended for testing and should not be used at the same time as the main mod.
